VOLT GUARDIAN: POWER BATTLE — Solar Harbour browser-game prototype

PLAY: Open index.html in a modern browser. Click START BATTLE.
Keyboard: Left/Right arrows move; Space or Up dodges; X or Enter fires an energy blast; R restarts.
Mobile: use the on-screen buttons.

PUBLISH FREE WITH GITHUB PAGES:
1. Upload index.html to the root of your GitHub repository.
2. Open Settings > Pages.
3. Under Build and deployment, choose Deploy from a branch, branch main, folder /(root), then Save.
4. Open the published URL shown on the Pages screen.

This is a first playable prototype, not a native app-store build. Replace the text/bolt mark with the official approved Solar Harbour logo if desired.
